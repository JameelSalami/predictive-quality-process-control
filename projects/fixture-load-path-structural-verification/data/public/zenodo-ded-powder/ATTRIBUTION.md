**Changes from source:** The included `paired-track-observations.csv`
uses a selected 23-track subset (tracks 28–50); validates process-track
identity and monitoring capture alignment; extracts calibrated physical
bead CTQs from macrograph scale bars, aligned laser-active IR summaries,
and commanded/process values; these normalized records are **not**
the creators' unmodified raw archives. Project regression metrics and
figures derived from these values are credited to the same record.
